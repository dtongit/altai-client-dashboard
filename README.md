# Altai Optima Client Dashboard

Персональный кабинет клиента платформы автономных ИИ-продавцов **Altai Optima** (бренд **Вера**), лендинг: [optima.altaiweb.online](https://optima.altaiweb.online).

Кабинет предназначен для руководителей бизнеса, директоров по продажам (РОП) и операторов для мониторинга показателей окупаемости (ROI), контроля живых переписок в мессенджерах и оперативного вмешательства (пауза конкретного диалога или всей системы).

---

## 🌟 Ключевые возможности

1. **Сводка и бизнес-аналитика (Executive Pulse)**:
   * **KPI воронки**: общее число обработанных диалогов, квалифицированные лиды (BANT), конверсия в заявку (%).
   * **Скорость первого ответа (TTFT)**: замер в миллисекундах (в 30 раз быстрее штатного сотрудника).
   * **Экономический эффект**: расчет сэкономленного ФОТ менеджеров по отношению к затратам на ИИ.
   * **График динамики**: суточная активность по сообщениям и сессиям за последние 7 дней.
   * **Распределение по каналам**: Telegram, WhatsApp, веб-виджет Tilda.

2. **Центр живых диалогов (Live Chats & Human Takeover)**:
   * Просмотр ленты реальных обращений клиентов в реальном времени.
   * **Кнопка «Пауза ИИ / Перехват диалога»**:
     * Замораживает автоответы Веры для выбранного чата.
     * Менеджер отвечает напрямую в Telegram, WhatsApp или amoCRM без перебивания роботом.
     * Входящие реплики клиента продолжают аккуратно фиксироваться в истории со статусом `paused_takeover`.
   * **Карточка BANT-квалификации**:
     * Имя, телефон клиента, выявленная потребность, зафиксированный бюджет.
     * Ссылка на созданную сделку в amoCRM / Битрикс24.

3. **Управление системой и каналами (System Health & Emergency Kill Switch)**:
   * **Главный рубильник (Master Switch)**: мгновенная глобальная пауза автоответов ИИ во всех каналах (для инвентаризации или обновления скриптов).
   * Статусы коннекторов мессенджеров (Telegram Bot API, Green-API WhatsApp, Webhooks).
   * Статус синхронизации с CRM.

4. **База знаний Веры (Knowledge Base)**:
   * Просмотр актуальных материалов: позиционирование, каталог/прайс-лист, скрипты снятия возражений.
   * Кнопка быстрой отправки заявки на обновление базы знаний инженеру Altai.

## 🛠️ Технологический стек

* **Фреймворк**: [Next.js 15 (App Router, Turbopack, Standalone Output)](https://nextjs.org/)
* **Язык**: TypeScript
* **Стилизация**: Tailwind CSS v4, Lucide Icons, clsx, tailwind-merge
* **Графика и графики**: Recharts
* **Бэкенд-интеграция**: REST API с FastAPI бэкендом `ai-sdr` (`/api/v1/client/*`)
* **Автономный демо-режим**: встроенный Fallback Mock Layer (позволяет демонстрировать интерфейс заказчикам даже при выключенном бэкенде)

## 🚀 Локальный запуск и разработка

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения
Скопируйте пример окружения:
```bash
cp .env.example .env.local
```
Параметры:
* `NEXT_PUBLIC_API_URL` — URL к бэкенду `ai-sdr` (по умолчанию `http://localhost:8000/api/v1/client`).

### 3. Запуск сервера разработки
```bash
npm run dev
```
Интерфейс будет доступен по адресу: `http://localhost:3000`.

### 4. Проверка сборки
```bash
npm run build
```

---

## 🐳 Сборка и деплой в Docker

Сборка легковесного production-образа:
```bash
docker build -t altai-client-dashboard .
```

Запуск через Docker Compose:
```bash
docker compose up -d
```
